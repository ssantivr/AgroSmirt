# 🌱 AgroSmirt

### 💧 Sistema Inteligente de Monitoreo y Riego de Cultivos

> **AgroSmirt** es un sistema inteligente diseñado para monitorear las condiciones de un cultivo y automatizar el proceso de riego, utilizando sensores, Arduino y una aplicación desarrollada en Java.

---

## 🌿 ¿Qué es AgroSmirt?

AgroSmirt permite **monitorear en tiempo real la humedad del suelo y las condiciones climáticas** para determinar cuándo un cultivo necesita agua.

El sistema puede **activar y detener automáticamente el riego**, generar alertas y almacenar la información obtenida para analizar el comportamiento del cultivo y optimizar el consumo de agua.

---

## 🎯 Objetivo

Desarrollar una solución tecnológica que permita **automatizar el riego de cultivos**, utilizando los datos obtenidos mediante sensores para tomar decisiones de manera eficiente y reducir el desperdicio de agua.

---

## 👨‍💻 Proyecto

**AgroSmirt** combina **agricultura + tecnología + automatización** para crear una solución orientada al uso eficiente del agua y al monitoreo inteligente de cultivos.

> 🌱 **Tecnología para cultivar mejor.** 💧
