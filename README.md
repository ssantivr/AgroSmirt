# 🌱 AgroSmirt

> *Smart Agriculture & Automated Irrigation System*

> 💧 *Sistema inteligente para el monitoreo, control y automatización del riego de cultivos.*

---

## 🎯 Objetivo

> 🌱 *Desarrollar una solución tecnológica inteligente capaz de automatizar el riego de cultivos, utilizando información obtenida mediante sensores para tomar decisiones eficientes y reducir el desperdicio de agua.*

### 🚀 Objetivos del Sistema

#### 💧 Monitoreo del suelo

Supervisar en tiempo real la humedad del suelo para identificar las necesidades de agua de los cultivos.

#### 🌦️ Análisis climático

Obtener información sobre las condiciones ambientales para considerar su influencia en las necesidades de riego.

#### 🤖 Automatización del riego

Automatizar el proceso de riego mediante decisiones basadas en la información obtenida por los sensores.

#### 🚰 Control de motores y bombas

Controlar automáticamente los motores y bombas encargados de suministrar agua a los cultivos.

#### ⚠️ Sistema de alertas

Generar alertas cuando se presenten condiciones que requieran atención durante el funcionamiento del sistema.

#### 📊 Registro y análisis de información

Registrar los datos obtenidos para facilitar su consulta, seguimiento y análisis.

#### 💦 Optimización del consumo de agua

Utilizar únicamente el agua necesaria para el cultivo, buscando reducir el desperdicio y mejorar la eficiencia del sistema.

---

## 🌱 Sobre AgroSmirt

> *AgroSmirt es un sistema inteligente diseñado para el monitoreo y automatización del riego de cultivos.*

El sistema utiliza **sensores conectados a Arduino** para obtener información en tiempo real sobre la **humedad del suelo y las condiciones ambientales**.

Los datos obtenidos por los sensores son procesados mediante **Java 21**, permitiendo analizar la información y tomar decisiones automáticas sobre el proceso de riego.

La información recopilada es almacenada en **MySQL**, permitiendo gestionar y conservar los datos generados durante el funcionamiento del sistema.

> 💡 **Nuestro propósito:** utilizar la tecnología para optimizar el uso del agua y mejorar el cuidado de los cultivos.
